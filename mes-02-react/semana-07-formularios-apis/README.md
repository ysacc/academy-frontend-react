# Semana 7 — Formularios y APIs en React

## Objetivo

Integrar formularios, validación, estados de petición y consumo de APIs dentro de React.

## Requisitos

- formulario controlado;
- validación básica;
- loading/error/success;
- servicio de API separado;
- render condicional;
- evitar doble submit.

## Homework

Construye una pantalla CRUD parcial o buscador avanzado conectado a una API.
