# Semana 2 — JavaScript moderno

## Objetivo

Consolidar JavaScript moderno para trabajar con datos y lógica reutilizable antes de entrar a React.

## Temas

- `const` / `let`.
- destructuring.
- spread/rest.
- template literals.
- funciones y arrow functions.
- arrays y objetos.
- `map`, `filter`, `find`, `reduce`.
- módulos ES.

## Homework

Implementa utilidades para transformar una colección de productos/usuarios.

## Requisitos

- funciones puras cuando aplique;
- no mutar datos de entrada innecesariamente;
- exportar funciones;
- usar métodos de array adecuados;
- nombres claros.
