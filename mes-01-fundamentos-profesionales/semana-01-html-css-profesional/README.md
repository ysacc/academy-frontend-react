# Semana 1 — HTML/CSS profesional

## Objetivo

Nivelar fundamentos y transformar una maqueta en una landing semántica, accesible, responsive y organizada.

## Debes practicar

- HTML semántico.
- Accesibilidad básica.
- CSS organizado.
- Flexbox/Grid.
- Responsive.
- DevTools.

## Homework

Construye una landing con `header`, navegación, hero, sección de beneficios, cards y footer.

### Requisitos

- HTML semántico.
- `meta viewport`.
- navegación accesible;
- al menos una zona con Flexbox y una con Grid;
- media query;
- imágenes responsivas;
- foco visible en controles interactivos;
- sin estilos inline como solución principal.
