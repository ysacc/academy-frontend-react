# Semana 4 — Git, Pull Requests y Scrum

## Objetivo

Trabajar una tarea como se haría dentro de un equipo: ticket, branch, commits, PR y Code Review.

## Homework

Completa un ticket asignado en tu repo personal utilizando el flujo profesional.

## Requisitos

- ticket con criterios de aceptación;
- branch descriptiva;
- mínimo 2 commits coherentes;
- PR con descripción;
- evidencia de tests locales;
- responder al menos una observación de review.

## Test local

```bash
npm run test:week04
```

Entrega el enlace del PR o repo.
