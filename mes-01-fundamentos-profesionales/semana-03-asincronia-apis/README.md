# Semana 3 — Asincronía y APIs

## Objetivo

Consumir una API REST separando obtención, transformación y presentación de datos.

## Requisitos

- `async/await`;
- `fetch`;
- validación de `response.ok`;
- `try/catch`;
- estados loading/error/empty/success;
- función de transformación de datos;
- interfaz usable.

## Homework

Construye una app pequeña con una API pública y al menos una búsqueda o filtro.
