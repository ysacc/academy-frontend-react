# Evaluación

La evaluación combina validación técnica y revisión humana.

## Criterios

- 30% funcionamiento y cumplimiento de requisitos.
- 20% calidad y organización del código.
- 15% uso de Git y trazabilidad de cambios.
- 15% capacidad de explicar decisiones.
- 10% testing y manejo de errores.
- 10% UX, accesibilidad y presentación.

## Tests locales

Los tests validan requisitos objetivos. No sustituyen el Code Review.

## Code Review

El instructor revisa:

- legibilidad;
- separación de responsabilidades;
- nombres;
- reutilización;
- manejo de estados y errores;
- deuda técnica evidente;
- comprensión real del alumno.

## Proyecto integrador

Además se evalúan alcance, planificación, calidad del README, deploy, presentación técnica y aplicación de feedback.
