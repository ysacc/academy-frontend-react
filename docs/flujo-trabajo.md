# Flujo de trabajo profesional

A partir de la Semana 4 se practica de forma explícita:

```text
Ticket → análisis → branch → implementación → tests locales → commit → push → Pull Request → Code Review → corrección
```

## Convenciones sugeridas

Branches:

```text
feature/academy-123-user-card
fix/academy-124-loading-state
```

Commits:

```text
feat: add user card component
fix: handle api error state
test: cover user service
refactor: extract fetch logic
```

## Entrega académica

El PR puede practicarse dentro del repositorio personal del alumno. La entrega al instructor es el enlace del repo o PR indicado para la semana.
