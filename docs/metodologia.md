# Metodología — Frontend React

## Formato

- 12 semanas.
- 4 horas en vivo por semana.
- 2 sesiones de 120 minutos.

## Clase A — concepto + práctica guiada

- 0–15 min: repaso, preguntas y conexión con la semana anterior.
- 15–40 min: concepto principal.
- 40–70 min: live coding.
- 70–100 min: ejercicio guiado.
- 100–115 min: debugging y preguntas.
- 115–120 min: checkpoint y mini tarea.

## Clase B — aplicación + pairing + revisión

- 0–15 min: revisión de checkpoint.
- 15–35 min: ampliación conceptual.
- 35–65 min: desarrollo aplicado.
- 65–95 min: code pairing.
- 95–110 min: tests locales / Code Review.
- 110–120 min: homework y cierre.

## Code pairing

- Driver: escribe y verbaliza decisiones.
- Navigator: revisa, cuestiona, anticipa errores y propone el siguiente paso.
- Cambiar roles cada 10–15 minutos.

## IA como copiloto

Puede usarse para investigar, depurar, generar tests, documentar y refactorizar. El alumno debe poder explicar, verificar y modificar todo código asistido por IA.

## Entrega

El alumno ejecuta los tests en local, sube su trabajo a su repositorio y envía el enlace al instructor. No se usa CI automático en este repo.
