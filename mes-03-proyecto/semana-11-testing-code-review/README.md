# Semana 11 — Testing y Code Review

## Objetivo

Convertir el MVP en una release candidate mediante pruebas, revisión cruzada y correcciones.

## Requisitos

- tests relevantes;
- flujo principal sin errores críticos;
- revisión de otro alumno;
- feedback recibido y aplicado;
- accesibilidad y responsive revisados;
- consola limpia en flujo principal.
