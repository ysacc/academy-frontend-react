# Semana 12 — Deploy y presentación final

## Objetivo

Publicar y defender técnicamente el proyecto integrador.

## Entrega final

- repo público o accesible al instructor;
- README completo;
- URL de deploy;
- proyecto responsive;
- tests locales en verde;
- historial de commits razonable;

2. Demo del flujo principal.
3. Arquitectura / decisión técnica.
4. Dificultad y solución.
5. Qué mejorarías después.
