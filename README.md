# Academy Frontend React

Ruta práctica para formarse como Frontend Developer con JavaScript, TypeScript, React, APIs, Git, Scrum y testing mediante proyectos y flujo profesional de trabajo.

## Estructura del programa

- 12 semanas.
- 48 horas en vivo.
- 2 clases por semana.
- 2 horas por sesión.
- Tests ejecutados únicamente en local.
- Entregas mediante repositorio personal del alumno.
- Code Review y code pairing durante las clases.

## Ruta

| Semana | Tema | Resultado |
| --- | --- | --- |
| 1 | HTML/CSS profesional | Landing accesible y organizada |
| 2 | JavaScript moderno | Utilidades y lógica reusable |
| 3 | Asincronía y APIs | App con API pública |
| 4 | Git + Scrum | Flujo Ticket → Branch → PR → Review |
| 5 | React fundamentos | Componentes y props |
| 6 | Hooks | Estado, efectos y composición |
| 7 | Formularios + APIs | App React conectada a API |
| 8 | TypeScript + arquitectura + testing | Frontend mantenible y testeable |
| 9 | Backlog y planificación | Proyecto integrador definido |
| 10 | Desarrollo | MVP funcional |
| 11 | Testing + Code Review | Release candidate |
| 12 | Deploy + presentación | Proyecto publicado y defendido |

## Estructura semanal

Este repositorio público contiene material del alumno:

- `README.md`: objetivos, homework, requisitos y entrega.
- `starter/`: punto de partida sin resolver la tarea.
- tests locales: validación objetiva cuando corresponda.

El material docente, guiones de clase, preguntas internas y referencias de revisión se mantienen en un repositorio privado del instructor.

## Flujo de entrega

```text
starter → trabajo en clase → homework → tests locales → repo personal → enlace al instructor → Code Review
```

No hay GitHub Actions en este repositorio. Los tests se ejecutan localmente para que el alumno aprenda a interpretar sus propios fallos y evitar ruido de CI.

Consulta `docs/metodologia.md`, `docs/evaluacion.md` y `docs/flujo-trabajo.md`.

## Ecosistema Academy

Ruta recomendada:

1. [Desde Cero](https://github.com/ysacc/academy-desde-cero) — fundamentos de desarrollo web.
2. **Frontend React** — especialización frontend profesional.
3. [Full Stack](https://github.com/ysacc/academy-fullstack) — backend, bases de datos e integración Full Stack.

Programas complementarios:

- [Preparación para Entrevistas](https://github.com/ysacc/academy-entrevistas).
- [Mentoría](https://github.com/ysacc/academy-mentoria).

### Requisito recomendado

Llegar con fundamentos sólidos de HTML, CSS, JavaScript, Git y consumo básico de APIs, o demostrar un nivel equivalente.

### Siguiente paso recomendado

Al completar el proyecto integrador y poder defender decisiones de arquitectura frontend, continuar con **Academy Full Stack** o usar **Preparación para Entrevistas** si el objetivo inmediato es empleabilidad.
